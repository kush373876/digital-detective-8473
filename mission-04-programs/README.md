### Compiler vs Interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Translates before program execution | Executes instructions at runtime |
| Typical output | Often machine code or executable | Usually executes without a separate native executable |
| One example | C compiler | Python interpreter |
| One advantage | Can produce efficient executable programs | Convenient for testing and interactive execution |

### Explanation

A compiler translates source code into another form before the program runs. An interpreter executes instructions at runtime. Compilers often produce executable output, while interpreters make testing and development convenient. Python uses a combination of compilation to bytecode and interpretation by its virtual machine.
