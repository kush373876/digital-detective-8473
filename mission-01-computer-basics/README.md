
# Mission 1 – Know Your Computer

## Task 1.1 – Understanding the IPOS Cycle

IPOS stands for Input, Processing, Output and Storage. These are the four basic operations performed by a computer.

### Practical Example: Typing and Saving a Document

| Stage | Description | Hardware |
|---|---|---|
| Input | Typing text using the keyboard | Keyboard |
| Processing | CPU processes the keystrokes and instructions | CPU and RAM |
| Output | The typed text appears on the screen | Monitor |
| Storage | The document is saved for future use | SSD |

### My Understanding

The IPOS cycle explains how a computer receives data, processes it, produces results and stores information for future use.






## Task 1.2 – Hardware vs Software

### Hardware

Hardware refers to the physical components of a computer that can be seen and touched.

Examples:
1. Keyboard – Used to enter data.
2. Monitor – Displays information.
3. CPU – Processes instructions.
4. SSD – Stores data and files.

### Software

Software refers to programs and instructions that tell the computer hardware what to do.

Examples:
1. macOS – Operating system.
2. Visual Studio Code – Code editor.
3. Google Chrome – Web browser.
4. Python – Programming language.

### My Understanding

Hardware represents the physical components of a computer, whereas software provides the instructions that make the hardware perform different tasks.




## Task 1.3 – Computer Systems Around You

### My Understanding

Computer-based systems are used in everyday life to perform specific tasks. They receive input, process information and produce output. Examples include ATMs, traffic signals and smart TVs.
