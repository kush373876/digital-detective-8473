## 2. Work Completed

### Basic Terminal Commands
- `pwd` – Display current working directory.
- `ls` – List files and directories.
- `cd` – Change directory.
- `mkdir` – Create a directory.
- `touch` – Create an empty file.

### File Management
- `echo` – Write text into a file.
- `cat` – Display file contents.
- `>` – Overwrite file contents.
- `>>` – Append text to a file.
- `cp` – Copy files.
- `mv` – Move or rename files.
- `rm` – Remove files.
- `rmdir` – Remove empty directories.

### Flags and Pipes
- `ls -l` – Display detailed file information.
- `ls -a` – Display hidden files.
- `ls -la` – Combine detailed and hidden-file listings.
- `|` – Pass the output of one command to another.
- `wc -l` – Count lines.
- `grep` – Search for specific text.
- `grep -i` – Search without case sensitivity.
