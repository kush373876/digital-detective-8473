# Mission 0 — Repository Setup

## 1. Task / objective

Create a GitHub repository and prepare the required folder structure for the Digital Detective assignment.

## 2. Work completed

- Created the local project folder.
- Created all nine mission folders.
- Created README.md files.
- Created the required Python files.
- Opened the project in VS Code.

## 3. Commands / tools used

| Command / Tool | Purpose |
|---|---|
| python3 --version | Check Python version |
| git --version | Check Git version |
| mkdir | Create directories |
| touch | Create empty files |
| pwd | Display current directory |
| find | Display folder structure |
| VS Code | Edit project files |

## 4. My understanding

A repository is a place where project files and their changes are managed using Git. Organising the assignment into separate mission folders makes the project easier to understand and maintain.

## 5. Difficulties faced

Initially, I entered Git commands inside the Python interpreter instead of the Terminal shell.

## 6. How I resolved them

I exited the Python interpreter using exit() and executed the commands in the normal Terminal shell.
