
# The Digital Detective

## About This Project

This project is part of my Diwali Independent Learning Assignment.

The objective is to explore computer fundamentals, practise Terminal commands, understand operating systems, learn Python programming, explore number systems, use Git and GitHub, and understand computer networks.

- Computer fundamentals and IPOS

- Terminal commands and file management

- Python programming
- Binary, decimal and hexadecimal number systems
- Text encoding
- Git and GitHub
- Computer networking

## Running the Number Converter

Open Terminal in the project folder and run:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```
